The funniest sick-day excuse, written by a small deterministic Python program: `main.py` writes a single 87-character line to `$MAKEFUN_OUTPUT_DIR/entry.txt` — "My goldfish died and I need to grieve; HR's bereavement policy doesn't specify species." The line was picked from 8 drafted candidates (see `CANDIDATES.md`), scored against the judge's own criteria (on-subject, funny, original, voice, tight), and revised once to tighten it: the "I can't come in" opening came out and a semicolon took the place of the second "and", so the grief and the loophole sit side by side as a deadpan claim instead of a story.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out python3 main.py
cat ./out/entry.txt
```
